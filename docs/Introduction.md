မင်္ဂလာပါ ။ ကျွန်တော် က လက်ရှိ Data Engineer တစ်ယောက်အနေနဲ့ အလုပ်လုပ်ကိုင်နေပါတယ်။ လုပ်ငန်းခွင်က အတွေ့အကြုံတွေ၊ လေ့လာမှတ်သားမိသမျှတွေကို ပြန်လည်မျှဝေလိုစိတ်နဲ့ ဒီ blog ကို မတ်လ ၁၁ ရက်နေ့ ၊ ၂၀၂၅ မှာ စခဲ့တာပါ။

Data Engineering Field မှာ လူသိများတဲ့ Simon Späti ရဲ့ [Second Brain Knowledge Vault](https://www.ssp.sh/brain/data-engineering/) အပေါ် အားကျစိတ်ကို အခြေခံပြီး မြန်မာဘာသာ နဲ့ ရေးသားထားတဲ့ Data Engineering ဆိုင်ရာ သုတစွယ်စုံမျိုးလေး ဖြစ်လာဖို့ ရည်မှန်းထားပါတယ်။ ကိုယ်တိုင် လေ့လာနေဆဲမို့ အမှားအယွင်းတစ်စုံတစ်ရာ ပါဝင်ခဲ့ရင် အချိန်မရွေး ဆက်သွယ် အကြံပြုနိုင်ပါတယ်။
