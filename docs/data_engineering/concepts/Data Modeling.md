Business လိုအပ်ချက်နဲ့ အညီ data ကို design ဆွဲဖို့က အင်မတန် အရေးကြီးတဲ့ အဆင့် ဖြစ်ပါတယ်။ ဒီအဆင့်မှာ Databases တွေ (သို့) Data Warehouse တွေမှာ data ကို ဘယ်လိုပုံစံ သိမ်းဆည်းမလဲ ၊ စီမံခန့်ခွဲမလဲ ၊ ရယူသုံးစွဲမလဲ ဆိုတာတွေအတွက် လမ်းပြမြေပုံ (Blueprint) အသွင်ဆောင်ပါတယ်။

အသုံးများတဲ့ Data Modeling နည်းလမ်းတွေကတော့ - 
1. Inmon Data Model
2. Dimensional Model
3. Data Vault Model
4. OBT (One Big Table) Model

နည်းလမ်းတစ်ခုချင်းဆီ ရဲ့ အသေးစိတ် ကို ဆက်လက်ရေးသားသွားပါမယ်။
