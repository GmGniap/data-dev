"Data Granularity" (သို့မဟုတ်) "Grain of table" ကို မြန်မာလို ဘာသာပြန်ဖို့ ခက်ခဲပါတယ်။ "ဒေတာတစ်ကြောင်းချင်းဆီရဲ့ ရှိရင်းတရား" လို့ ဘာသာပြန်လို့ ရမလား မပြောတတ်ဘူး။ ဆိုလိုတာကတော့ table (သို့) view တစ်ခုရဲ့ individual row တစ်ကြောင်းချင်းဆီရဲ့ level of details ကို တိုင်းတာတာ ဖြစ်ပါတယ်။ (ဥပမာ - အရပ်စကားနဲ့ ပြောမယ်ဆိုရင် တိုင်းဒေသကြီး လယ်ဗယ်လား ၊ မြို့နယ် လယ်ဗယ်လား ၊ ရပ်ကွက်လယ်ဗယ်လား စသဖြင့် ပြောကြသလိုပါပဲ)။ ဒါက ဒေတာတွေကို Join (သို့မဟုတ်) Aggregate လုပ်တဲ့အခါမှာ အင်မတန် အရေးပါပါတယ်။

- ==Finely grained table== ဆိုတဲ့ အသုံးအနှုန်းက အသေးစိတ် level of details ကို ဆိုလိုတာပါ ။ (ဥပမာ - row တစ်ကြောင်းချင်းဆီက transaction တစ်ခုချင်းဆီကို millisecond level အထိ ကိုယ်စားပြုတာမျိုး)
- ==Coarse grained table== ဆိုတာကကျတော့ ယေဘုယျဆန်တဲ့ (အသေးမစိတ်တော့တဲ့) level of details ကို ဆိုလိုတာပါ။ (ဥပမာ - တစ်ရက်ချင်းဆီ/တစ်ပတ်ချင်းဆီ/တစ်လချင်းဆီ ရဲ့ transaction စုစုပေါင်းအရေအတွက် Count )

Granularity ကို များသောအားဖြင့် unique row ဖြစ်အောင် ပြုလုပ်နိုင်သော columns တွေ အားလုံးကို စုပေါင်းပီး ဖော်ပြကြပါတယ်။
