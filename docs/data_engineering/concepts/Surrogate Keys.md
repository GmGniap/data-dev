- Surrogate Key ဆိုတာက row တစ်ကြောင်းချင်းဆီက ဒေတာ ကို အခြေခံပြီး ထုတ်ထားတဲ့ Unique Identifier key ဖြစ်ပါတယ်။ နားလည်လွယ်အောင် ပြောရမယ် ဆိုရင် row တစ်ကြောင်းချင်းဆီက multiple columns တွေကနေ ရလာတဲ့ cell value တွေ အပေါ် Hashing Algorithm တစ်ခုခု apply လုပ်ပြီး ထွက်လာတဲ့ value ကို Surrogate Key value အနေနဲ့ သုံးတဲ့ ပုံစံမျိုးပါ။ များသောအားဖြင့် Natural Primary Key မရှိတဲ့အခြေအနေမျိုးမှာ table တိုင်းအတွက် Surrogate Key ဖန်တီးဖို့ လိုအပ်ပါတယ်။
