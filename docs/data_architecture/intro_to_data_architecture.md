# Data Architecture Principles
1. Data ဆိုတာက မျှဝေအသုံးပြုရမယ့် အရာတစ်ခု ဖြစ်ပါတယ်။ 


# Data Architecture components
Modern Data Architecture တစ်ခုမှ အောက်ဖော်ပြပါ အရာများ ပါဝင်ဖို့ လိုပါတယ်
- Data Pipelines 
	- ဒေတာတွေအတွက် ဘယ်လိုပုံစံ စုဆောင်းမယ် ၊ မျှဝေမယ် ၊ ပြုပြင်မယ် ၊ အသုံးချမယ် စတဲ့ အဆင့်တွေပါဝင်တဲ့ process တစ်ခုလုံးကို data pipeline လို့ ခေါ်ပါတယ်။ ဒီထဲမှာ Data Collection , Refinement, Storage, Analysis and Delivery (Reporting) တွေ ပါဝင်ပါတယ်။
- Cloud Storage
	- Data Architectures တိုင်း အားလုံးမှာတော့ cloud storage သုံးတယ် လို့ မဆိုလိုပါဘူး။ ဒါပေမယ့် အခုနောက်ပိုင်း Modern Data Architectures တွေ တော်တော်များများမှာတော့ public, private, hybrid cloud တွေကို အသုံးချလာကြပါတယ်။ (မှတ်ချက် - Cloud storage/computing စျေးနှုန်းတွေ ကျဆင်းလာတာကြောင့်လဲ ပါမယ်)
